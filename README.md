Here are the requirements for the assignment:

The First name text box can only contain letters; the backspace key must also work. 
The Last name text box can only contain letters; the backspace key must also work. 
The City text box can only contain letters; the backspace key must also work. 
The Zip code text box can contain numbers and the hyphen (-), but not letters; the backspace key must also work. 
When the Save button is clicked, all the controls on the form (except the buttons) must be validated for completeness. 
The user should be able to press the Enter key on the keyboard to activate the event handler behind the Save button. 
The user should be able to press the Escape (Esc) key on the keyboard to activate the event handler behind the Exit button. 
The Exit button closes the form. The Clear button resets all the controls on the form and sets the focus to the First name text box. 
The tab order must be correct.
